# TritonCal — UCSD TSS 周课表

[English](README.md) | 简体中文

TritonCal 是电脑端 Chrome / Arc 浏览器扩展。它读取 UCSD TSS 首页已经加载的课程，显示典型周和 Final 视图，完整显示课程代码、课名、时间和教室，并可导出日历文件（.ics）或独立的离线 HTML 课表。这是独立学生项目，与 UC San Diego 官方没有隶属或背书关系。

最新发布：**v0.6.0**，在 [GitHub Releases](https://github.com/Relay-studio-ucsd/TritonCal/releases) 下载。`main` 上的代码是 0.7.0：功能相同、目录结构已重组，尚未发布。Chrome 应用商店因开发者注册需付费，暂不上架，需要手动加载。

## 安装

不需要安装 Node、不需要打开开发者工具，也不需要复制接口响应。

1. 从 [Releases 页面](https://github.com/Relay-studio-ucsd/TritonCal/releases) 下载 `tritoncal-extension-preview-<版本号>.zip`，解压得到 `extension` 文件夹。
2. 在浏览器地址栏输入 `chrome://extensions` 并回车（Arc 也可输入 `arc://extensions`）。
3. 打开页面右上角的 **开发者模式 / Developer mode**。
4. 点击 **加载已解压的扩展程序 / Load unpacked**，选择解压出来的 `extension` 文件夹；选中的文件夹里应直接有 `manifest.json`。
5. 自己登录 [TSS 官网](https://tss.ucsd.edu/fiori/)，回到首页，**整页刷新一次**（Mac 按 `⌘R`，Windows 按 `Ctrl+R`）。
6. 点击页面右下角的 **课表**，再点 **打开周视图**。也可点击浏览器工具栏的 TritonCal 图标，再点 **打开周视图**。

界面默认中文，点 **English** 可切换。浏览器会提示此本地扩展可在 `tss.ucsd.edu` 运行，因为它需要读取 TSS 页面已经收到的课表响应。

## 功能

- **典型周** 归并每周固定时段；**Final** 显示受支持的 UCSD 期末周内已读取的安排。
- 按课上色或单色（7 个预设色或自定义颜色）；每个课块完整显示课名、时间和教室。
- 在周课表、课表面板或工具栏弹窗点 **English / 中文** 即可切换并记住选择，不跟随浏览器语言；日期和星期随之切换。扩展管理页中的名称由浏览器决定。
- **导出已读取课程 (.ics)** 导出当前 TSS 标签页实际收到的全部上课日期，按钮显示总条数。ICS 的固定标签统一为英文（如 Lecture、Exam），课程名和教室保留学校原文。
- **下载手机离线课表 (.html)** 生成独立网页（见下节）。

## 手机离线课表（实验功能）

在电脑端周课表点击 **下载手机离线课表 (.html)**，会得到 `tritoncal-offline.html`。它只包含显示需要的课程信息，不包含 TSS 事件号和原始响应；保留下载时的语言，独立打开不需要插件或网络，并可按实际日期切换自然周。

可将文件传给自己的手机，用支持本地 HTML 的浏览器打开。文件预览器可能不运行网页脚本；如果只显示标题而没有课程，请反馈手机型号和打开方式。文件是下载时的快照，不会自动同步，选课变化后需重新下载。它包含个人课表，请勿当成插件安装包发给别人。手机真机尚未验收。

## 安装遇到问题

- **找不到扩展管理页**：在浏览器顶部地址栏输入 `chrome://extensions` 并回车，不要在网页的搜索框里输入。
- **没有“加载已解压的扩展程序”**：先打开扩展管理页右上角的“开发者模式”。
- **提示找不到清单文件**：ZIP 必须先解压，选择里面直接能看到 `manifest.json` 的文件夹。
- **已安装但 TSS 没有按钮**：确认扩展已启用，回到 TSS 首页整页刷新。
- **按钮显示“等待 TSS 页面加载课表”**：确认 TSS 自带的课程区域已正常加载。插件依赖页面本身收到的课表，无法替 TSS 补发请求。
- **典型周为空**：确认 TSS 已加载完整学期，只有达到频次条件的常规时段才显示。
- **Final 为空**：可能是期末日期尚未加载，或学期未被校历覆盖且 TSS 没有标记考试；请核对官网的 Final Examination。没有读取到课程不代表没有选课。

仍有问题时，反馈浏览器名称和按钮上显示的文字。

## 更新和卸载

- **更新**：用新版本的 `extension` 文件夹替换原文件夹内容，在扩展管理页点击 TritonCal 的重新加载按钮，再刷新 TSS。使用期间不要移动或删除该文件夹。
- **卸载**：在扩展管理页找到 TritonCal，点击 **移除 / Remove**，再刷新或关闭 TSS 标签页。已下载的 `.ics` 和 `.html` 文件需自行删除。

## 分享与试用

给别人试用时**只分享** Release 的 ZIP 或 `extension` 文件夹，不要分享项目的 `input/` 目录，它可能含个人课表和学号。对方需要用自己的账号登录 TSS，并在自己的浏览器手动加载。

试用时检查什么（先完成电脑端，日历导入可选）：

- 右下角是否出现“课表”。
- 典型周中每个固定时段是否只出现一次；Final 是否包含官网确认的期末，未标记项目是否注明“期末周安排”。
- 任意两门课的时间、课程名称和教室是否正确且完整显示。
- “按课上色”和“单色”能否切换；单色预设和自定义颜色是否立即生效、刷新后是否保留。

反馈格式：`浏览器：____；入口：有/无；典型周和 Final：正确/有问题；时间和教室：正确/有问题；问题描述：____。`

不需要提供账号、密码、学号或接口响应；若自愿发截图，只截插件区域。

## 数据与限制

插件只被动读取 TSS 页面已经收到的课表响应：不主动请求、不重放、不轮询 TSS，不自动点击，不参与登录，也不上传课表；没有服务器、统计或在线翻译。课程只保存在当前标签页内存中，只有单色选择（存于 TSS 的本地存储）和语言选择（存于扩展自身存储）保存在本地。导出的文件包含个人课表，请勿随意分享。详见 [隐私说明（英文）](extension/PRIVACY.md)。

- 只有 TSS 的 `Room` 有值时才显示教室；`Location` 可能只是校园名，插件不会把它当作教室。
- TSS 加载的数据不完整时，课表也不完整。典型周按“课程代码 + 类型 + section + 星期 + 起止时间 + 教室”归并，出现次数达到已读取周数一半（向上取整）才显示，考试不计入；目前没有学期筛选。
- Final 按 [UCSD 官方校历](https://blink.ucsd.edu/instructors/resources/academic/calendars/2026.html) 覆盖 2026 秋、2027 冬和春；这些学期的期中不进入 Final，没有考试标记的安排显示为“期末周安排”，请以课程详情中的 Final Examination 为准。其他学期只显示 TSS 明确标记的考试，可能包含期中。Final 为空不代表没有考试。
- 安装插件后需刷新 TSS 首页，让页面重新加载课表；插件不会主动请求它。
- 目前以电脑端为主；Windows 外观和手机真机尚未验收。导出文件是快照，不会自动更新。

## 开发

```sh
git clone https://github.com/Relay-studio-ucsd/TritonCal.git
cd TritonCal
npm test
npm run package
```

需要 Node.js ≥ 20，无 npm 依赖。`npm run package` 重新生成内置翻译，并按白名单在 `out/` 生成预览包和商店候选包。

全部技术文档（英文）见 [MAINDOC.md](MAINDOC.md)，AI 助手从 [AGENTS.md](AGENTS.md) 开始。个人抓取数据放在被忽略的 `input/`，生成物放在被忽略的 `out/`。
