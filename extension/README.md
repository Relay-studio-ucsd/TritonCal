# TritonCal 浏览器插件实验版

[English installation guide](README.en.md)

这是从 TSS 真实响应读取课程的浏览器插件预览版 0.6.0。TSS 页面右下角会出现“课表”按钮；点开后可进入按时间排列的周视图，切换“典型周 / Final”与颜色模式，并下载 `.ics` 日历文件或离线课表网页。当前主要支持电脑端；这是独立学生项目，与 UC San Diego 官方没有隶属关系。

## 中英双语

在周课表右上角、课表面板或工具栏弹窗点击 **English / 中文**，界面立即切换并记住选择，不跟随浏览器语言。首次默认中文；日期和星期随选择切换。浏览器扩展管理页中的名称由浏览器决定。课程名称、教室保留学校原文。离线 HTML 会保留下载时的语言，独立打开不依赖插件；ICS 的固定标签统一为英文（如 Exam、Lecture）。

## 数据怎么来

- `capture.js` 在 TSS 页面的 MAIN world 被动观察页面自己发出的 `fetch` / XHR 响应，只接收 `EVENT_TIMETABLE_SRV/EventListSet`；如果它藏在 OData `$batch` 中，仅提取课表行，不转交同一批次的其他数据。
- `content.js` 将响应转换成日期、时间、课程名、教室，并在 TSS 页面右下角显示小面板；原始响应不保存，插件不发 TSS 请求，不登录，也不自动点击页面。
- 工具栏弹窗只显示入口提示和“打开周视图”按钮，通过浏览器内部消息打开当前 TSS 页面中的课表。没有后端、分析服务或外部依赖。

## 手动加载

1. 到本仓库 [Releases 页面](https://github.com/Relay-studio-ucsd/TritonCal/releases) 下载 `tritoncal-extension-preview-0.6.0.zip`，解压后得到 `extension` 文件夹。
2. 打开 Arc 或 Chrome，在地址栏输入 `chrome://extensions` 并回车。Arc 也可以输入 `arc://extensions`。
3. 打开页面右上角的 **开发者模式 / Developer mode**。
4. 点击 **加载已解压的扩展程序 / Load unpacked**，选择解压出来的 `extension` 文件夹。选中的文件夹里面应直接有 `manifest.json`。
5. 自己登录 [TSS 官网](https://tss.ucsd.edu/fiori/)，回到首页，**整页刷新一次**。Mac 按 `⌘R`，Windows 按 `Ctrl+R`。
6. 点击页面右下角的 **课表**，再点 **打开周视图**。也可点击浏览器工具栏的 TritonCal 图标，再点 **打开周视图**。

不需要安装 Node、不需要打开开发者工具，也不需要复制接口响应。当前没有上架商店，需要按以上步骤手动加载。

浏览器会提示此本地扩展可在 `tss.ucsd.edu` 运行，因为它需要读取 TSS 页面已经收到的课表响应。源码可在本目录逐文件查看。

**给别人试用时只分享 `extension/` 目录或预览版 ZIP**，不要分享项目的 `input/` 目录；后者可能含个人课表和学号。对方需要用自己的账号登录 TSS，并在自己的浏览器按上面的步骤手动加载。当前尚未上架扩展商店。2026-10-20 已收到第二个账号可以使用的反馈，特殊课程情况仍需逐项核对。

Release 提供的 `tritoncal-extension-preview-0.6.0.zip` 只有插件代码、语言包、图标与说明，没有真实抓取数据。完整的数据处理说明见 [PRIVACY.md](PRIVACY.md)。

历史实测：用户在 Arc 的 TSS 官网确认入口及真实课程，并在 0.5.3 刷新后确认 Final 能显示两门考试。0.6.0 已通过中英 Chrome 假数据界面检查；Windows 真机外观仍待确认。

## 帮忙试用时检查什么

先完成电脑端检查即可，日历导入是可选功能。

- 右下角是否出现“课表”。
- 典型周中每个固定时段是否只出现一次；Final 是否包含官网确认的期末，未标记项目是否注明“期末周安排”。
- 任意两门课的时间、课程名称和教室是否正确且完整显示。
- “按课上色”和“单色”能否切换；单色预设和自定义颜色是否立即生效、刷新后是否保留。

反馈格式：`浏览器：____；入口：有/无；典型周和 Final：正确/有问题；时间和教室：正确/有问题；问题描述：____。`

不需要提供账号、密码、学号或接口响应。遇到问题时，描述按钮显示的文字即可；若自愿发截图，只截插件区域。

## 安装遇到问题

- 找不到扩展管理页：在浏览器顶部地址栏输入 `chrome://extensions`，按回车，不要在网页的搜索框里输入。
- 没有“加载已解压的扩展程序”：先打开扩展管理页右上角的“开发者模式”。
- 提示找不到清单文件：ZIP 必须先解压，选择里面直接能看到 `manifest.json` 的 `extension` 文件夹。
- 已安装但 TSS 没有按钮：确认扩展已启用，回到 TSS 首页整页刷新。
- 按钮显示“等待 TSS 页面加载课表”：确认 TSS 自带的课程区域已正常加载。插件依赖页面本身收到的课表，无法替 TSS 补发请求。
- 典型周显示零条：确认 TSS 已加载完整学期，只有达到频次条件的常规时段才显示。Final 为空可能是期末日期尚未加载，或学期未被校历覆盖且 TSS 没有标记考试；请核对官网 Final Examination。没有读取到课程不代表没有选课。仍有问题时反馈页面文字和浏览器名称。

## 手机离线课表（实验功能）

在电脑端周课表点击 **下载手机离线课表 (.html)**，会得到 `tritoncal-offline.html`。它只包含显示需要的课程信息，不包含 TSS 事件号和原始响应。可将文件传给自己的手机，尝试用支持本地 HTML 的浏览器打开。文件预览器可能不运行网页脚本；如果只显示标题而没有课程，请反馈手机型号和打开方式。

离线 HTML 仍按实际日期切换自然周。文件是下载时的快照，不会自动同步；选课变化后需要重新下载。它包含个人课表，请勿当成插件安装包发给别人。手机真机打开与视觉验收尚未完成。

## 更新和卸载

更新时，用新版本的 `extension` 文件夹替换原文件夹内容，在扩展管理页点击 TritonCal 的重新加载按钮，再刷新 TSS。不要在使用期间移动或删除该文件夹。

卸载时，在扩展管理页找到 TritonCal，点击 **移除 / Remove**，再刷新或关闭 TSS 标签页。已下载的 `.ics` 和 `.html` 文件可自行删除。

## 已知限制

- 只有 `EventListSet` 的 `Room` 非空时才显示教室；响应中的 `Location` 可能只是校园名，插件不会把它误当教室。
- 典型周按“课程代码 + 类型 + section + 星期 + 起止时间 + 教室”归并，不同日期的出现次数达到已读取覆盖周数的一半（向上取整）才显示，考试排除在典型周之外。覆盖周数用最早至最晚已读取有效事件所在的自然周估算；数据不完整时无法代表整个学期，目前没有学期筛选。
- Final 按 [UCSD 官方校历](https://blink.ucsd.edu/instructors/resources/academic/calendars/2026.html) 显示期末周内已读取的安排，覆盖 2026 秋、2027 冬和春。这些学期的期中不进入 Final；未标记项显示“期末周安排”，不修改原始考试标记，不据日期认定每条都是考试。其他学期仅保留 TSS 明确标记的考试，并提示核对是否为期末；不按时长或往年日期推测。空白不代表没有考试。
- 单色可选 7 个预设色或自定义颜色，偏好保存在 TSS 本地存储中，不新增扩展权限。
- “导出已读取课程”会把当前 TSS 标签页实际收到的全部有效上课日期导出，按钮显示总条数；它不会猜测没有加载到的课程。下载的 `.ics` 包含个人课表，请自行决定导入哪个日历。
- 用户需要在安装插件后刷新 TSS 首页，使页面再次正常加载课表响应。插件不会主动请求它。

验证：在项目目录执行 `npm test`，或直接用 Node ≥20 执行 `node --test tests/*.test.cjs`。`npm run package` 生成只含发行文件的 ZIP。
