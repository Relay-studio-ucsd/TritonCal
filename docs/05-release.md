## 商店介绍草稿

名称：TritonCal — TSS 周课表

简短说明：在 UCSD TSS 中查看清晰的周课表、课程时间和教室，可切换颜色并导出日历。

详细说明：

TritonCal 在 TSS 页面右下角提供“本周课表”入口，把页面已经加载的课程整理成按时间排列的周课表。

你可以查看本周、上一周和下一周，完整阅读课程代码、名称、时间和教室，并在按课配色与单色之间切换。需要时可下载 ICS 日历文件或离线课表网页。

插件只在 TSS 站点运行，不需要额外账号，不主动请求课表，也不上传课表。请先自行登录 TSS，在安装后刷新首页。显示和导出的范围以 TSS 页面实际加载的数据为准；未提供的教室会显示“教室待确认”。

这是独立学生项目，不代表 UC San Diego 官方。手机离线网页仍属于实验功能。
