## 五项变更

1. 时间网格顶部和底部各留 12px；时间标签、横线、课程块使用相同偏移，保持时间比例和对齐。
2. 右下角面板外层裁切圆角，内层负责滚动与高度限制，使用细滚动条。
3. 工具栏弹窗只保留提示与打开周视图按钮。内容脚本收到打开消息后展示课表；未捕获数据、非 TSS 页面和消息失败都有提示。
4. 单色模式提供 7 个预设色点及原生自定义取色器。背景为同色低透明度，左边色条为原色。仅颜色值存于 TSS 的 localStorage，存储被禁用时本次会话仍可选色；课程数据不持久化。
5. 页面内课表改为典型周 / Final；入口简化为“课表”，去掉自然周导航。离线 HTML 和 ICS 仍按实际日期导出。

## 归并规则与边界

- 典型周用课程代码（未知时回退事件名称）、类型、section、星期、起止时间、教室作为分组键。每个不同日期只计一次，显式考试排除。
- 没有可靠的学期边界元数据，因此用最早至最晚已读取有效事件所跨的自然周估算覆盖周数（含考试所在周）。出现次数达到一半、向上取整才保留；界面显示估算周数和阈值，提示需让 TSS 加载完整学期。
- 每个固定时段只显示一次，周一至周五固定显示，符合条件的课程涉及周末时扩展到七列；表头只显示星期。
- Final 严格要求 `isExam === true`，保留最早至最晚考试之间的连续真实日期，空数据明确显示没有考试标记。不会凭日期或时长猜测考试。
